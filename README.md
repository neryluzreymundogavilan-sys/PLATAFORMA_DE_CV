# Generador Web de Currículum (CV) — Dossier Documental

Aplicación web interactiva para la creación de Currículum Vitae en formato A4 y anexado de dossier documental con sistema de registro de estudiantes y aprobación en el Panel de Administrador.

## Flujo de Registro y Aprobación
1. **Estudiantes y Egresados:** Al abrir el enlace desde sus dispositivos, ingresan a la pantalla de bienvenida, hacen clic en **Registrarme**, completan sus datos (Nombres, Correo, Teléfono y Contraseña) y envían su solicitud.
2. **Panel de Administrador:** Las solicitudes se guardan y se sincronizan automáticamente en el **Panel de Administrador**, donde puedes aceptarlas ("Aceptar") o rechazarlas.
3. **Inicio de Sesión:** Una vez que el estudiante es aceptado por la administradora, puede ingresar con su correo y contraseña para utilizar el generador de CV.
4. **Administradora:** Puede entrar directamente sin contraseña haciendo clic en "Entrar como Administradora" o usando el parámetro `?admin=1`.
